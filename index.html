진행 가이드 (상호 리뷰 품앗이)

1) 방 진입

카톡 오픈채팅 탭 → 검색창에 키워드 입력. 확인된 키워드: 리뷰 리뷰 품앗이 인스타 품앗이 인스타 좋아요 품앗이 유튜브 품앗이 맞팔 네이버 예약후기. 링크 공유방은 open.kakao.com/o/…을 카톡에서 열면 참여 화면으로 이동.

2) 자기 정보 + 리뷰 요청 올리기

방에 "우리 사업장 + 어떤 플랫폼 리뷰를 요청하는지 + 대신 그쪽 리뷰를 달아준다"는 내용을 올림. 아래 템플릿 사용.

3) 상호 매칭 → 리뷰 작성

상대방이 우리 리뷰를 달아주고, 우리는 그쪽 사업장 리뷰를 달아줌. 1:1 채팅으로 매칭되는 방도 있음. 각 플랫폼별 작성 방법은 아래 참고.

4) 완료 확인

리뷰가 실제 노출되는지 각 플랫폼에서 확인 후 방에 "완료/감사" 표시. 정산이 있는 방(영수증 리뷰)은 2주 단위 정산 공지 확인.

플랫폼별 리뷰 작성 방법

카카오맵 (카톡 계정 연동)

카카오맵에서 사업장 검색 → 리뷰 작성. 영수증 불필요. 카톡 계정으로 작성.

구글 (구글 지도)

구글 지도에서 사업장 → 리뷰 작성. 구글 계정으로. GBP "리뷰 요청" 링크로 상대에게도 요청 가능.

네이버 (플레이스/지도)

네이버 플레이스에서 사업장 → 리뷰. 일부는 영수증/방문 인증 필요. 예약 후 "이용완료" 처리 시 리뷰 가능한 구조(미용실·뷰티 등).
